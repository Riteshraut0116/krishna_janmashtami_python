**# 🕉️ Lord Krishna Drawing with Python Turtle 🎨**

---

## 📝 Project Description

This project uses Python's built-in `turtle` graphics library to create a beautiful and intricate portrait of Lord Krishna. The script programmatically draws the artwork, including Krishna's face, adornments, and the iconic peacock feather, line by line.

---

## 🖼️ Output

After running the script, a window will appear and you will see the drawing of Lord Krishna being created. Once the script is finished, your beautiful artwork is ready! 🎉

![Final Output](krishna_python_file/pythonpoutput.png)

## 🚀 How to Run

Follow these steps to generate the drawing on your machine.

---

### Prerequisites

Make sure you have Python installed (version 3.8 or newer is recommended).

---

### Installation & Execution

1.  **No Installation Needed:** The `turtle` module comes built-in with Python, so no extra packages are required.

2.  **Run the Script:** Open your terminal or command prompt, navigate to the project directory, and run the following command:
    ```bash
    python index.py
    ```
